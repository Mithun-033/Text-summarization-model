# Text-summarization-model
A complete pipeline to train and test a deep learning model for text summarization

## Setup workflow

1. **Fork** this repository.

2. **Clone** your fork.

```bash
git clone https://github.com/<username>/Text-summarization-model.git
cd Text-summarization-model
```

3. **Open** the project.

```bash
code .
```

4. **Install** the dependencies.

```bash
pip install uv
uv sync
```

5. **Create a branch.**

```bash
git checkout -b feature/<feature-name>
```

6. **Implement** one or more missing components.

7. **Commit and push.**

```bash
git add .
git commit -m "Implement <component>"
git push origin feature/<feature-name>
```

8. **Open a Pull Request** to this repository.
